WINDOWS SERVER MANAGEMENT




Cambiare SID
Per cambiare il SID di una macchina Windows Server usando Sysprep, eseguire il seguente comando da un prompt dei comandi con privilegi amministrativi:
C:\Windows\System32\Sysprep\sysprep.exe /generalize /oobe /shutdown
Spiegazione degli argomenti:
/generalize: Rimuove le informazioni specifiche della macchina, incluso il SID.
/oobe: All'avvio successivo, Windows mostrerà la schermata di benvenuto Out-of-Box Experience (OOBE).
/shutdown: Dopo l'operazione, il sistema verrà spento ( /reboot invece per riavviare).

Nota: Se il server è parte di un dominio, andrà rimosso dal dominio prima di eseguire Sysprep, altrimenti potrebbero verificarsi problemi con l'accesso dopo il riavvio.

Visualizzare SID
Per visualizzare il SID della macchina su Windows Server (o qualsiasi sistema Windows), usare uno dei seguenti metodi:

Metodo 1: Usare WMIC (Prompt dei comandi)
Aprire un Prompt dei comandi come amministratore ed eseguire:
wmic useraccount get name,sid
Questo comando elenca il SID di tutti gli account utente locali, incluso l'account Administrator.

Per ottenere il SID della macchina (detto anche Machine SID), usare:
wmic computersystem get domain,name
Il SID della macchina è il SID dell'account Administrator, senza il segmento finale.

Metodo 2: Usare PowerShell
Aprire PowerShell come amministratore ed eseguire:
Get-WmiObject Win32_UserAccount | Select Name, SID
Oppure, per ottenere direttamente il SID della macchina:
$ComputerSID = (Get-WmiObject Win32_ComputerSystem).Domain + "\" + (Get-WmiObject Win32_ComputerSystem).Name Write-Output "SID della macchina: $ComputerSID"

Metodo 3: Usare PsGetSid (da Sysinternals)
Questo metodo utilizza lo strumento PsGetSid della suite Sysinternals:

Scaricare PsGetSid da Microsoft Sysinternals.

Aprire un Prompt dei comandi come amministratore.

Eseguire:
psgetsid
Nota: Il SID della macchina è utile per identificare univocamente un sistema in rete. Se due macchine hanno lo stesso SID (ad esempio, se è stato clonato un server senza eseguire Sysprep), possono verificarsi problemi di autenticazione.
