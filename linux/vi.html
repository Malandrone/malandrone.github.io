Linux Server Management


1. Aprire un file con vi
Per aprire o creare un file utilizzando vi, specificare il percorso del file come argomento. Se il file non esiste, vi lo creerà quando verrà salvato.

Se il file richiede privilegi di amministratore, è possibile utilizzare sudo.
sudo vi <path_del_file>

2. Modalità di funzionamento di vi
vi utilizza diverse modalità operative. La modalità principale è quella di comando, nella quale i tasti premuti vengono interpretati come comandi. Per modificare il contenuto del file è necessario entrare nella modalità di inserimento.

Dopo aver aperto un file, normalmente ci si trova in modalità comando. Per eseguire un'operazione di scrittura è quindi necessario passare alla modalità inserimento.

3. Entrare nella modalità inserimento
Premere i per entrare nella modalità di inserimento (Insert). Da questo momento è possibile digitare e modificare normalmente il testo del file.
i

4. Uscire dalla modalità inserimento
Premere Esc per uscire dalla modalità inserimento e tornare alla modalità comando. Questo passaggio è necessario prima di eseguire comandi come il salvataggio o la chiusura del file.
Esc

5. Salvare il file
Dopo essere tornati in modalità comando, digitare :w e premere Invio. Il comando w significa write e salva le modifiche senza chiudere vi.
:w

6. Salvare e chiudere vi
Per salvare le modifiche e chiudere contemporaneamente vi, premere Esc, digitare :wq e premere Invio.

w salva il file, mentre q (quit) chiude l'editor.
:wq

7. Uscire senza salvare
Per annullare tutte le modifiche effettuate dall'ultimo salvataggio e chiudere vi, premere Esc, digitare :q! e premere Invio.

Il carattere ! forza l'uscita anche quando sono presenti modifiche non salvate.
:q!

8. Uscire da vi
Se il file non presenta modifiche non salvate, è possibile chiudere vi semplicemente con :q. Premere prima Esc, digitare il comando e premere Invio.
:q

9. Annullare l'ultima modifica
In modalità comando, premere u per annullare l'ultima modifica effettuata. È possibile premere più volte u per annullare progressivamente più modifiche.
u

10. Cercare del testo
Per cercare una parola o una stringa all'interno del file, premere Esc, digitare /testo e premere Invio.

Dopo aver effettuato la ricerca, premere n per passare alla corrispondenza successiva. Premere N per tornare alla corrispondenza precedente.
/testo

11. Passare alla riga specificata
In modalità comando è possibile spostarsi direttamente a una determinata riga utilizzando :numero_riga. Ad esempio, :25 porta il cursore alla riga 25.
:25

12. Visualizzare i numeri di riga
Per visualizzare i numeri delle righe all'interno di vi, utilizzare il comando :set number. I numeri sono particolarmente utili quando si lavora con file di configurazione o quando si deve individuare rapidamente una determinata riga.
:set number

13. Rimuovere la visualizzazione dei numeri di riga
Per nascondere nuovamente i numeri di riga, utilizzare :set nonumber.
:set nonumber
