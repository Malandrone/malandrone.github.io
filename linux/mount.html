Linux Server Management


1. Aggiornare l'elenco dei pacchetti
Aggiornare l'elenco dei pacchetti disponibili nei repository configurati sul sistema. È consigliabile eseguire questo comando prima di installare nuovi pacchetti.
sudo apt update

2. Installare cifs-utils
Installare il pacchetto cifs-utils, che fornisce gli strumenti necessari per montare condivisioni SMB/CIFS su Linux. Questo permette di accedere a una cartella condivisa da un server Windows, Samba o altro dispositivo compatibile SMB.
sudo apt install cifs-utils

3. Creare il file delle credenziali
Creare il file /etc/smb-cred, nel quale verranno memorizzati username e password utilizzati per autenticarsi alla condivisione SMB.

Utilizzare nano per creare e modificare il file.
sudo nano /etc/smb-cred

4. Inserire le credenziali
Inserire nel file le credenziali dell'utente autorizzato ad accedere alla condivisione.

Sostituire TUO_UTENTE con il nome utente e LA_TUA_PASSWORD con la relativa password.

Il file deve contenere una voce per riga.
username=TUO_UTENTE
password=LA_TUA_PASSWORD

5. Proteggere il file delle credenziali
Impostare i permessi 600 sul file delle credenziali. In questo modo solamente root potrà leggere e modificare il file.

Questo passaggio è particolarmente importante perché il file contiene una password in chiaro.
sudo chmod 600 /etc/smb-cred

6. Creare il punto di mount
Creare la directory /mnt/smbshare, che verrà utilizzata come punto di mount della condivisione SMB.

L'opzione -p permette di creare anche le directory genitore eventualmente mancanti.
sudo mkdir -p /mnt/smbshare

7. Modificare il file fstab
Aprire il file /etc/fstab. Questo file contiene le configurazioni dei filesystem e delle condivisioni che possono essere montati automaticamente dal sistema.
sudo nano /etc/fstab

8. Aggiungere la condivisione SMB a fstab
Aggiungere al file /etc/fstab la configurazione della condivisione.

Sostituire SERVER con l'indirizzo IP o il nome del server SMB e SHARE con il nome della condivisione.

cifs indica il filesystem utilizzato per il collegamento SMB. credentials specifica il file contenente le credenziali. vers=3.0 richiede l'utilizzo del protocollo SMB 3.0. _netdev indica che il mount dipende dalla disponibilità della rete. nofail permette al sistema di completare l'avvio anche se la condivisione non è raggiungibile. x-systemd.automount permette a systemd di gestire il mount automaticamente quando viene effettuato l'accesso al punto di mount.
//SERVER/SHARE /mnt/smbshare cifs credentials=/etc/smb-cred,vers=3.0,_netdev,nofail,x-systemd.automount 0 0

9. Ricaricare la configurazione di systemd
Dopo aver modificato /etc/fstab, ricaricare la configurazione di systemd. Questo permette a systemd di rilevare le modifiche alle unità generate a partire dal file fstab.
sudo systemctl daemon-reload

10. Verificare e montare le condivisioni definite in fstab
Utilizzare mount -av per leggere le configurazioni presenti in /etc/fstab e tentare di montare le risorse configurate.

L'opzione -a indica di montare tutti i filesystem configurati in fstab, mentre -v abilita un output più dettagliato delle operazioni eseguite.
sudo mount -av

11. Verificare il contenuto della condivisione
Visualizzare il contenuto della directory /mnt/smbshare.

L'opzione -l mostra informazioni dettagliate sui file, mentre -a include anche eventuali file nascosti.

Se il mount è avvenuto correttamente, verranno visualizzati i file e le directory presenti nella condivisione SMB.
ls -la /mnt/smbshare
