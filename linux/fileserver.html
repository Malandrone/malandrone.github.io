Linux Server Management


1. Creare l'utente Linux per Samba
Creare un nuovo utente Linux denominato smbuser. Questo utente verrà utilizzato per accedere alla condivisione Samba. Durante l'esecuzione del comando verrà richiesta una password per l'utente.
sudo adduser smbuser

2. Aggiungere l'utente al database degli utenti Samba
Aggiungere smbuser al database degli utenti di Samba. La password Samba può essere diversa dalla password dell'account Linux. Durante l'esecuzione verrà richiesta la password che verrà utilizzata per l'accesso alla condivisione.
sudo smbpasswd -a smbuser

3. Abilitare l'utente Samba
Abilitare l'account Samba appena creato. Il comando permette all'utente smbuser di autenticarsi al server Samba.
sudo smbpasswd -e smbuser

4. Assegnare la proprietà della directory
Assegnare la proprietà della directory /srv/storage all'utente e al gruppo smbuser. In questo modo l'utente utilizzato per accedere alla condivisione Samba sarà anche il proprietario della directory.
sudo chown smbuser:smbuser /srv/storage

5. Impostare i permessi della directory
Impostare i permessi 770 sulla directory. Il proprietario e il gruppo avranno permessi completi di lettura, scrittura ed esecuzione, mentre gli altri utenti non avranno accesso alla directory.
sudo chmod 770 /srv/storage

6. Verificare proprietà e permessi
Verificare proprietario, gruppo e permessi della directory /srv/storage. L'opzione -d permette di visualizzare le informazioni relative alla directory stessa invece del suo contenuto.
ls -ld /srv/storage

7. Creare un backup della configurazione di Samba
Prima di modificare la configurazione di Samba, creare una copia di sicurezza del file smb.conf. In caso di errore sarà così possibile ripristinare rapidamente la configurazione originale.
sudo cp /etc/samba/smb.conf /etc/samba/smb.conf.bak

8. Modificare la configurazione di Samba
Aprire il file di configurazione principale di Samba utilizzando nano. La configurazione della nuova condivisione verrà aggiunta alla fine del file.
sudo nano /etc/samba/smb.conf

9. Configurare la condivisione storage
Aggiungere in fondo al file /etc/samba/smb.conf il seguente blocco.

[storage] definisce il nome della condivisione. path indica la directory Linux condivisa. browseable = yes permette alla condivisione di essere visualizzata durante la navigazione delle risorse di rete. read only = no abilita la scrittura. guest ok = no impedisce l'accesso anonimo. valid users limita l'accesso all'utente smbuser. force user fa sì che le operazioni sui file vengano eseguite come smbuser. create mask e directory mask definiscono i permessi massimi per file e directory creati tramite Samba.
[storage] path = /srv/storage
browseable = yes
read only = no
guest ok = no
valid users = smbuser
force user = smbuser
create mask = 0660
directory mask = 0770

10. Verificare la configurazione di Samba
Prima di riavviare Samba, verificare la sintassi del file di configurazione. testparm analizza smb.conf e segnala eventuali errori di configurazione. È consigliabile eseguire sempre questo controllo dopo aver modificato il file.
sudo testparm

11. Riavviare il servizio Samba
Riavviare il servizio smbd per applicare la nuova configurazione.
sudo systemctl restart smbd

12. Verificare lo stato del servizio
Controllare che il servizio Samba sia correttamente in esecuzione. L'opzione --no-pager impedisce a systemctl di aprire il risultato all'interno del pager, mostrando direttamente l'output nel terminale.
sudo systemctl status smbd --no-pager

13. Abilitare l'avvio automatico di Samba
Abilitare il servizio smbd all'avvio del sistema. In questo modo Samba verrà avviato automaticamente dopo ogni riavvio del server.
sudo systemctl enable smbd

14. Accedere alla condivisione dal client
Una volta completata la configurazione, la condivisione storage sarà raggiungibile dalla rete tramite il percorso UNC: \\IP_DEL_SERVER\storage.

Sostituire IP_DEL_SERVER con l'indirizzo IP della macchina Linux. Quando richiesto, utilizzare le credenziali dell'utente Samba smbuser.
\\IP_DEL_SERVER\storage
