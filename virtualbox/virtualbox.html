VirtualBox Management


Installazione delle Guest Additions su Linux
Le Guest Additions devono essere installate nel sistema operativo guest per utilizzare funzionalità come le cartelle condivise e una migliore integrazione tra host e guest. Dalle impostazioni della VM, collegare la ISO delle Guest Additions come unità ottica virtuale.
Installare i prerequisiti necessari alla compilazione dei moduli del kernel delle Guest Additions.
sudo apt update
sudo apt install build-essential dkms linux-headers-$(uname -r)
Verificare le unità disponibili e individuare il dispositivo ottico contenente la ISO delle Guest Additions. Nell'esempio il dispositivo è /dev/sr0.
lsblk
L'output dovrebbe essere simile al seguente:

NAME MAJ:MIN RM SIZE RO TYPE MOUNTPOINTS
sda 8:0 0 50G 0 disk
├─sda1 8:1 0 1M 0 part
└─sda2 8:2 0 50G 0 part /
sr0 11:0 1 51M 1 rom
Creare un punto di mount e montare l'unità ottica.
sudo mkdir -p /mnt/vbox
sudo mount /dev/sr0 /mnt/vbox
Verificare che nella ISO sia presente l'installer VBoxLinuxAdditions.run.
ls -la /mnt/vbox
Accedere alla directory contenente l'installer ed eseguirlo.
cd /mnt/vbox
sudo ./VBoxLinuxAdditions.run
Riavviare il sistema per caricare correttamente i moduli delle Guest Additions.
sudo reboot
Dopo il riavvio verificare che il modulo vboxguest sia stato caricato.
lsmod | grep vbox
Un output valido può contenere una riga simile alla seguente:

vboxguest 528384 2

Aggiunta di un disco VDI a una macchina virtuale
Prima di aggiungere il disco è consigliabile spegnere completamente la VM. Aprire Oracle VM VirtualBox Manager, selezionare la VM e aprire "Impostazioni" → "Archiviazione". Nel controller appropriato, ad esempio il controller SATA, selezionare "Aggiungi disco rigido" → "Scegli un disco esistente" e selezionare il file .vdi. Confermare con "OK".

Cartelle condivise con Windows
Prima di utilizzare le cartelle condivise è necessario che le Guest Additions siano installate nel sistema guest.

Nelle impostazioni della VM aprire "Cartelle condivise" → "Aggiungi nuova". Impostare:
- Percorso della cartella: percorso della cartella sull'host, ad esempio C:\folder
- Nome della cartella: nome della condivisione, ad esempio folder
- Selezionare "Montaggio automatico" se si desidera il montaggio automatico.

La cartella condivisa può essere raggiunta dal guest Windows tramite la condivisione VirtualBox.

Cartelle condivise con Linux
Nelle impostazioni della VM aprire "Cartelle condivise" → "Aggiungi nuova". Impostare il percorso della cartella sull'host e un nome per la condivisione, ad esempio folder.

Se viene selezionato il montaggio automatico, VirtualBox può montare la condivisione in un percorso sotto /media, ad esempio /media/sf_folder. Il percorso esatto può variare in base alla distribuzione e alla configurazione.
df -h
Se la cartella non viene montata automaticamente, creare un punto di mount e montare la condivisione utilizzando il nome assegnato nelle impostazioni di VirtualBox.
sudo mkdir -p /home/user/shared
sudo mount -t vboxsf folder /home/user/shared
Per consentire all'utente corrente di accedere alle cartelle condivise senza dover utilizzare ogni volta privilegi amministrativi, aggiungerlo al gruppo vboxsf. Dopo l'operazione effettuare il logout/login oppure riavviare il sistema.
sudo usermod -aG vboxsf $USER

Creazione di una cartella condivisa con PowerShell
È possibile configurare una cartella condivisa direttamente tramite VBoxManage. Eseguire PowerShell come amministratore e utilizzare il percorso di VBoxManage.exe. Sostituire NomeVM, cartella e C:\path\cartella con i valori reali.
cd "C:\Program Files\Oracle\VirtualBox"
.\VBoxManage.exe sharedfolder add "NomeVM" --name "cartella" --hostpath "C:\path\cartella" --automount --auto-mount-point "/mnt/path/cartella"
Il parametro --automount abilita il montaggio automatico della condivisione. Il parametro --auto-mount-point consente di specificare il punto di mount nel guest quando supportato dalla configurazione del sistema.

Configurazione dell'avvio automatico in modalità headless delle VM su Windows
Identificare la directory in cui sono memorizzate le macchine virtuali, ad esempio D:\VirtualMachines, e il nome esatto della VM, ad esempio "My_VM".

Successivamente aprire Utilità di pianificazione di Windows e creare una nuova attività pianificata.
Nella scheda "Generale" configurare l'attività in modo che possa essere eseguita anche quando l'utente non ha effettuato l'accesso e con privilegi elevati.
Nella scheda "Attivazione" creare un trigger "All'avvio" per eseguire l'attività quando viene avviato il sistema host.
Nella scheda "Azioni" selezionare "Avvio programma" ed impostare:
C:\Program Files\Oracle\VirtualBox\VBoxManage.exe
Nei parametri specificare:
startvm "My_VM" --type headless
Nel campo "Inizia in" impostare la directory di installazione di VirtualBox:
C:\Program Files\Oracle\VirtualBox
Nella scheda "Condizioni" disabilitare le condizioni non necessarie all'avvio della VM, in particolare quelle relative all'alimentazione e all'alimentazione da rete, se non pertinenti al server.
Nella scheda "Impostazioni" abilitare "Consenti esecuzione attività su richiesta". Se necessario, configurare il riavvio automatico dell'attività in caso di errore, ad esempio ogni 5 minuti, limitando il numero di tentativi a 3. È inoltre possibile impostare un limite massimo di esecuzione di 3 giorni e selezionare "Non avviare una nuova istanza" se l'attività è già in esecuzione.

Abilitazione della modalità headless su Windows
Questa configurazione è utile in scenari in cui le VM devono continuare a funzionare anche dopo il logout dell'utente. La funzionalità è disabilitata per impostazione predefinita e la documentazione Oracle la indica come sperimentale.
Chiudere VirtualBox e arrestare tutte le VM prima di modificare il registro. Creare la chiave:
HKEY_LOCAL_MACHINE\Software\Oracle\VirtualBox\VBoxSDS
All'interno creare un valore DWORD (32 bit) denominato ServerSession0 e impostarlo a 1.
New-Item -Path "HKLM:\Software\Oracle\VirtualBox\VBoxSDS" -Force
New-ItemProperty -Path "HKLM:\Software\Oracle\VirtualBox\VBoxSDS" -Name "ServerSession0" -PropertyType DWord -Value 1 -Force
Riavviare il sistema host affinché la modifica abbia effetto.
Dopo il riavvio è possibile verificare il valore configurato tramite PowerShell.
Get-ItemProperty "HKLM:\Software\Oracle\VirtualBox\VBoxSDS" -Name ServerSession0 -ErrorAction SilentlyContinue

Verifica delle macchine virtuali disponibili
Visualizzare le VM presenti su VirtualBox con PowerShell
& "C:\Program Files\Oracle\VirtualBox\VBoxManage.exe" list vms

Montare due dischi VDI su una macchina virtuale tramite CMD
Aprire il Prompt dei comandi di Windows come amministratore e spostarsi nella directory di installazione di VirtualBox.
cd "C:\Program Files\Oracle\VirtualBox"
Creare un disco virtuale VD1.vdi, in questo caso sarà collocato sull'unità D:\
VBoxManage createmedium disk --filename "D:\VD1.vdi" --size 1887436 --format VDI --variant Standard
Il parametro --size indica la capacità del disco in megabyte: il valore 1887436 MB corrisponde a circa 1,8 TB. Il formato utilizzato è VDI e la variante Standard crea un disco allocato dinamicamente, che occupa fisicamente sul disco host solo lo spazio effettivamente utilizzato dalla macchina virtuale.
Creare un secondo disco virtuale VD2.vdi collocato sull'unità E:\ con le stesse caratteristiche del primo disco.
VBoxManage createmedium disk --filename "E:\VD2.vdi" --size 1887436 --format VDI --variant Standard
Collegare VD1.vdi alla macchina virtuale utilizzando il controller SATA. Il disco viene collegato alla porta 1 del controller e viene configurato con il tipo di accesso writethrough.
VBoxManage storageattach "VM_NAME" --storagectl "SATA" --port 1 --device 0 --type hdd --medium "D:\VD1.vdi" --mtype writethrough
Collegare VD2.vdi alla stessa macchina virtuale utilizzando la porta 2 del controller SATA.
VBoxManage storageattach "VM_NAME" --storagectl "SATA" --port 2 --device 0 --type hdd --medium "E:\VD2.vdi" --mtype writethrough
