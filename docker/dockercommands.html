Docker Commands


Visualizzare i container in esecuzione
docker container ls

Visualizzare tutti i container creati
docker ps -a

Visualizzare le immagini importate
docker image ls

Importare un'immagine da un file tar
docker load file.tar

Creare un container da un'immagine - porte esposte
docker run -dit --network bridge --name nome_applicativo -p porta_esterna:porta_interna id_immagine

Creare un container da un'immagine - IP arbitrario
docker run -dit --network nome_subnet --ip 172.16.0.1 --name nome_applicativo -p porta_esterna:porta_interna id_immagine

Creare un container da un'immagine - persistenza/condivisione mount
docker run -d --name nome_container --restart unless-stopped --privileged -v /mnt/folder:/mnt/folder nome_immagine /sbin/init

Accedere ad un container - bash
docker exec -u 0 -it id_container bash

Accedere ad un container - /bin/sh
docker exec -u 0 -it id_container /bin/sh

Fermare un container
docker container stop nome_container

Eliminare un container
docker container rm nome_container

Eliminare un'immagine
docker image rm nome_immagine

Vedere l'IP di un container
docker inspect -f '{{range.NetworkSettings.Networks}}{{.IPAddress}}{{end}}' nome_container

Copiare un file da container su host
docker cp container_id:/file/path/nel/container /host/path/destinazione

Copiare un file da host verso il container
docker cp file.ext container_id:/percorso/destinazione

Rinominare un container
docker rename vecchio_nome nuovo_nome

Creare una subnet
docker network create --subnet=172.16.0.0/24 nome_subnet

Vedere i log di un container
docker logs nome_container

Creare un'immagine da un container
docker commit nome_container nome_immagine:nome_tag

Esportare un'immagine su un file compresso
docker save nome_image | gzip > /cartella/destinazione/nome_applicazione.tar.gz

Importare un'immagine da un file compresso
gunzip -c my_app.tar.gz | docker load
